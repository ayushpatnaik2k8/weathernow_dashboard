 # WeatherNow: City Weather Dashboard

A responsive city weather dashboard built during the SkillMe Full Stack Engineer Virtual Internship using HTML, CSS, JavaScript, and the Open-Meteo API.

## Features
- **Week 1:** Responsive static layout with city search bar, current weather card, and 7-day forecast cards.
- **Week 2:** Dynamic DOM rendering, `°C` / `°F` temperature unit toggle, and search form validation.
- **Week 3:** Live weather and 7-day forecast fetched asynchronously from Open-Meteo Geocoding and Forecast APIs with loading states and error handling.
- **Week 4:** Dynamic weather-based background themes and persistent last-searched city + temperature unit via `localStorage`.

## Tech Stack
- HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid, Dynamic Weather Themes)
- Vanilla JavaScript (`async/await`, DOM Manipulation, `localStorage`)
- Open-Meteo Geocoding & Forecast APIs
- Git & GitHub
